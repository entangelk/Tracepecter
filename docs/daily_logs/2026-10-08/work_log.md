- 피해: playground 다운로드 ~2시간분 폐기(오염 청크 삭제). qwen_3_4b·sdxl은 완료 시 정확 크기 검증 통과라 확정 무결.
- 수정(v4): curl `--retry` 제거 — 재시도를 Python 루프로 이동. 매 시도마다 수신량(`have`)을 다시 재서 `start+have`부터 이어받고, 과대(오염 서명)면 해당 청크를 삭제 후 재시작. `--retry`가 없으면 한 호출의 부분 수신은 항상 진짜 연속 접두사라 크기 기반 재개가 안전해진다.
