# Tracepecter 문서

패션 착용 이미지의 Photographic Realism Score(0~100)를 출력하는 vision 모델 MVP (Fashion Photo Realism Scorer, DB-01).
제품 정의는 `docs/project.md` §34, 문서 체계와 충돌 판정 규칙은 [`docs/sot.md`](sot.md) 참고.

| [`docs/sot.md`](sot.md) | 문서 체계·spec precedence·버전 로그 |
