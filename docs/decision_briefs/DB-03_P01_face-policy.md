# DB-03 — 착용컷 이미지의 얼굴 영역 처리 정책

**Status:** Open
**Related phase:** P01 (데이터 설계 전제)

## Decision needed

DB-01(옵션 A)로 도메인을 착용컷 패션으로 확정하면서 REAL·AI 양측 이미지에 얼굴이 포함된다. DB-01 후속 고려사항은 "모델이 의류 realism이 아니라 얼굴 위조 artifact에 반응하지 않도록 얼굴 영역 처리 정책을 REAL/AI 양측에 동일하게 적용"하는 것이다. 무처리로 둘지, 얼굴을 가릴지, 다른 처리를 할지는 제품 정의(점수가 무엇을 측정하는가)와 파이프라인 복잡도에 직결되므로 소유자가 정해야 한다.

## 배경 사실

- REAL(K-Fashion 스트리트 패션)은 대부분 얼굴이 포함된 착용컷이다. AI 생성 착용컷도 프롬프트에 따라 얼굴이 포함되며, 현 세대 생성기에서 얼굴·손은 왜곡 artifact가 가장 자주 나타나는 영역이다.
- 얼굴 artifact는 AI 판별에 가장 강한 신호 중 하나라, 처리하지 않으면 모델이 의류가 아닌 얼굴에 shortcut할 위험이 있다. 반대로 얼굴 품질도 "실제 촬영처럼 보이는 정도"의 한 요소이므로 정보를 무조건 버리는 것도 아니다.
- §4 비범위는 '얼굴 deepfake 탐지'(안면 영역 자체의 위변조 판정)이며, 착용컷 전체 사진에 얼굴이 포함되는 것은 별개다.

## Options

| Option | Description | Pros | Cons |
| --- | --- | --- | --- |
| A | **무처리** — 양측 모두 원본 그대로 사용("동일 적용"을 무처리로 충족). 생성 프롬프트에서 얼굴 노출 분포(정면·측면·후면·프레임 아웃)를 REAL 분포에 맞춰 설계 | 파이프라인 최단(§31). 추론·데모까지 전처리 계약 불필요. 얼굴 포함 realism 정보 보존 | 얼굴 artifact shortcut 위험. 위험 관리가 프롬프트 설계·사후 관찰에 의존 |
| B | **공통 블러/모자이크** — 얼굴 검출 후 REAL/AI 양측 동일하게 블러. 학습·검증·**추론 전 구간**에 동일 적용 | 얼굴 shortcut 원천 차단. 점수가 의류·배경·구도 realism에만 근거하게 됨 | 추론 파이프라인에 전처리 계약 추가(안 넣으면 train/test 분포 불일치). 검출 누락 시 비일관 적용. 얼굴 인근 artifact 정보 손실(§15 "강한 전처리는 artifact를 지운다"는 주의와 동일 논리). 구현·검증 비용 |
| C | **얼굴 제거 크롭** — 안면 상단을 잘라낸 구도로 변환 | 얼굴 신호 제거 | 착용컷 구도 훼손(전신룩이 아닌 반신화). REAL 분포 왜곡 + 크롭 artifact confound(DB-01이 옵션 B를 기각한 논리와 동일) — **비권장** |

## Recommendation + reason

**A.** MVP 단계에서 §31(단순성)·§15(강한 전처리 지양)·§35(thin-slice)에 가장 부합하고, 추론 시점(§22 API·§23 데모)에 전처리 계약이 생기지 않는다. shortcut 위험은 다음으로 관리한다.

1. **프롬프트 정합**(P01-04): 생성 프롬프트에 얼굴 노출 변형을 명시적으로 포함해 REAL의 얼굴 노출 분포와 어긋나지 않게 한다. "얼굴이 없으면 AI" 단서 자체를 제거.
2. **사후 관찰 트리거**(P06): failure analysis에서 오류가 얼굴 영역에 집중되는 패턴(예: 후면·안면 프레임 아웃 실사를 AI로 오판)이 확인되면 B(공통 블러)로 전환을 재상정한다. 전환 시 학습 데이터 재생성이 아니라 전처리 단계 추가로 가능하도록 P01 파이프라인은 전처리 단계를 분리해 둔다.

## Follow-up considerations

- 결정 시 P01 계획서(데이터 설계)와 P02 전처리 범위에 반영한다. B를 선택할 경우 추론 API 스펙(§22)에도 동일 전처리 적용을 명시해야 한다.
- K-Fashion 라벨에는 얼굴 좌표가 없으므로(부위 = 의류 영역), 어떤 옵션이든 얼굴 검출이 필요하면 별도 detector 의존성이 생긴다 — A 선택 시 불필요.

- 사람 평가 데이터(§21)의 얼굴 관련 설계.
