# DB-07 — P09 후보 검토 범위

**상태:** Resolved
**관련 페이즈:** [P09](../plan/phase_9_leakage_repair.md), P09-01 최종 그룹 확정·P09-02 진입

## 필요한 결정

P09의 초기 탐색 규칙을 실제로 적용하면 후보가 947,696쌍이다. REAL pHash≤26만 907,609쌍이며 우선순위 목록도 47,456쌍이다. 낮은 거리의 연결을 전부 동일 룩으로 확정하거나 미검토 후보를 모두 보수적 공동 배정하면 거대 성분과 오탐을 만들 수 있다. 모든 후보 수동 검토를 전제로 한 기존 계획의 종결 기준을 유지할지, 검토 범위를 제한하고 잔여 위험을 명시할지 결정한다.

근거는 [후보 요약](../../experiments/p09_leakage_repair/r1/grouping/candidate_run_01/summary.json)과 [48쌍 시각 검토](../../experiments/p09_leakage_repair/r1/grouping/visual_review_batch_01.csv)다. 새 검토에서 동일 룩 18·다른 룩 25·미확정 5쌍으로, 유사도 순위를 판정으로 대체할 수 없다.

## 선택지

| 옵션 | 실행 범위 | 장점 | 비용·한계 |
| --- | --- | --- | --- |
| A | 우선순위 검토로 축소. 기존 14쌍 재확인과 서로 다른 기존 그룹의 REAL 상위 500쌍(이번 48쌍 포함), GEN 상위 100쌍을 시작 범위로 고정한다. 확정 관계로 연결된 성분의 top-10 후보 이웃을 반복 검토해 새 확정 연결이 없으면 해당 범위를 종결한다. 검토한 미확정 관계는 재검토/보수적 공동 배정 근거를 남기고, 나머지는 미검토로 보존한다. 잔여 위험을 명시한 개발 재분할로 P09-02를 진행한다. | 실제 반례·확정 그룹 주변을 우선 수리하며 실행 가능한 검토 단위를 제공 | 범위 밖 동일 룩 누락을 배제하지 못함. 전체 후보 독립성 통과나 누출 완전 해결을 선언할 수 없음 |
| B | 기존 전수 검토 계획 유지. 초기 947,696쌍과 관계 확장 후 추가 후보의 판정/공동 배정 근거를 모두 갖출 때까지 P09-01 유지, 재분할 보류 | 명시된 후보 범위의 검토 누락을 줄임 | 매우 큰 검토량. 탐색 규칙 밖 누락·출처 교란·기존 평가 노출은 여전히 남음 |

## 권고와 이유

A를 권고한다. pHash≤26은 알려진 반례를 후보로 포함하기 위한 넓은 탐색 범위이지 정밀한 동일 룩 판별기가 아니다. 후보 전수 보존과 한계를 유지하면서 실제 시각 근거가 있는 관계부터 수리하는 편이 적절하다. 위 표본 수는 실행 범위를 명확히 하기 위한 작업자 제안이며 소유자 결정으로 확정되지 않았다.

## 후속 고려와 제외

- 두 옵션 모두 원본 6,000장·기존 primary·감사·주석을 보존한다. 실제 GEN 근사중복이 sd35 격리와 충돌하면 별도 결정한다.
- 새 평가도 개발 평가다. 신규 미접촉·출처/해상도/압축을 맞춘 holdout 필요성과 P08-07의 P07 비관문 결정은 불변이다.
- 후보 생성·첫 48쌍 검토·도구 검증은 어느 옵션에도 유효하므로 이미 수행했다. 최종 그룹 lock·재분할은 선택 뒤에 진행한다.

## 결정 결과

2026-10-20 소유자 선택: **A 방향 — 우선순위 검토로 조정하고 미검토 범위 명시**. 전체 후보를 보존하되 embedding 상위·촬영 시퀀스·확정 그룹 이웃부터 진행한다. 표의 초기 500/100쌍은 작업자가 정한 실행 범위이며 소유자가 별도로 지정한 수량이 아니다. 미검토 범위와 잔여 누출 위험을 숨기지 않는다.
